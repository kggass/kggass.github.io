# KG Entrega - Landing Page Profissional

Serviço logístico independente de entrega rápida de gás de cozinha (P13) e água mineral em Vila Velha, ES. Atuação em parceria com revendedores credenciados pela ANP.

## Tecnologias Utilizadas
* HTML5 Semântico (Acessibilidade e SEO otimizado)
* CSS3 Modular (Variáveis centralizadas e suporte a Dark Mode)
* JavaScript Moderno (ES6+, estruturado em namespaces orientados à responsabilidade)
